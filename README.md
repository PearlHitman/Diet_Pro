# Kitchen Assistant

AI-powered pantry-to-recipe PWA. Built with Vite + React + TypeScript.
Recipes generated by Claude (BYO API key, stored locally in your browser).

## Quick start (Windows)

### 1. Install Node.js (one-time)

Download the **LTS** version from <https://nodejs.org> and run the installer.
Click through with defaults. Open a new PowerShell window and verify:

```powershell
node --version
npm --version
```

Both should print version numbers. If "command not found", restart PowerShell.

### 2. Install project dependencies (one-time per clone)

In PowerShell, navigate to this folder and run:

```powershell
npm install
```

Takes ~30 seconds, downloads ~200MB into `node_modules`.

### 3. Run the dev server

```powershell
npm run dev
```

Vite will print two URLs:
- `Local: http://localhost:5173/` — open in your laptop's browser
- `Network: http://192.168.x.x:5173/` — open in your **iPhone's** Safari, same Wi-Fi

The iPhone URL is what makes this feel real. Hot-reload works on the phone too.

### 4. First-time setup inside the app

1. Open the URL → tap **Settings** (or the yellow warning banner).
2. Paste your Anthropic API key (get one at <https://console.anthropic.com/settings/keys>).
3. Tap **Test key** → should turn green.
4. Go back, fill out **Profile** (name, allergies, etc).
5. Go to **Pantry** → tap **+** → add some ingredients.
6. Back to home → **Generate recipe** → pick a meal type → wait ~20s.

### 5. Install as a PWA on your iPhone

1. Open the Network URL in Safari.
2. Tap the share button → **Add to Home Screen**.
3. Now it's an icon on your home screen and runs fullscreen without browser chrome.

## How data is stored

Everything lives in your browser's IndexedDB. Four keys under
`kitchen:` namespace: pantry, profile, recipes, settings.

**This means:** wiping browser data wipes the app. There's no cloud sync.
That's intentional for v1 — single-user, no auth, no privacy concerns.

To clear: Settings → Reset all data.

## How recipe generation works

1. User picks meal type on `/generate`.
2. `/generate/loading` builds a prompt from `pantry + profile + mealType`
   (see `src/lib/prompts.ts`).
3. The Anthropic SDK is called directly from the browser with
   `dangerouslyAllowBrowser: true`. Your key never leaves your device
   except to api.anthropic.com.
4. Claude returns JSON, we validate the shape, build `Recipe` objects.
5. They're saved (with starred-protection capped at 50) and shown on `/results`.

To tune the AI behavior, edit **`src/lib/prompts.ts`** — single source.

## Deployment to Vercel (free)

1. Create a GitHub account if you don't have one.
2. Create a new GitHub repo and push this folder:
   ```powershell
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<you>/kitchen-assistant.git
   git push -u origin main
   ```
3. Go to <https://vercel.com>, sign in with GitHub.
4. "Add New Project" → select the repo → click Deploy.
   Vercel auto-detects Vite. Done in ~1 minute.
5. You get a URL like `kitchen-assistant.vercel.app`. Every `git push` auto-deploys.

Open the URL on your iPhone → Add to Home Screen → ready.

## Troubleshooting

**`npm install` is stuck or fails.**
Run `npm install --no-fund --no-audit`. If still failing, delete
`node_modules` and try again.

**iPhone can't reach the Network URL.**
Windows Firewall may be blocking. Allow Node.js when the popup appears,
or temporarily disable the firewall to test. Phone and laptop must be on
the same Wi-Fi.

**"Invalid API key" but I just made one.**
Anthropic keys take ~30s to activate. Try again.

**Recipes come back in wrong language.**
Check Profile → Language. The generated recipes respect this setting.

**App icon is generic.**
Replace `public/icons/icon-192.png`, `icon-512.png`, `icon-512-maskable.png`
with proper icons. The SVG in `icon.svg` is a placeholder.
